# Kleinanzeigen Monitor → Telegram

Проверяет заданные поисковые запросы на kleinanzeigen.de каждые 5 минут
и присылает новые объявления в Telegram. Работает бесплатно на GitHub Actions,
без своего сервера.

## Шаг 1. Создать Telegram-бота

1. Открой Telegram, найди `@BotFather`.
2. Отправь `/newbot`, придумай имя и username бота.
3. BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxx` — сохрани его.
4. Напиши своему новому боту любое сообщение (например "привет") — это нужно,
   чтобы бот "увидел" тебя.
5. Узнай свой `chat_id`: открой в браузере
   `https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates`
   (подставь свой токен вместо `<ТВОЙ_ТОКЕН>`), в ответе найди поле
   `"chat":{"id": ...}` — это и есть твой chat_id.

## Шаг 2. Создать репозиторий на GitHub

1. Зарегистрируйся на github.com (бесплатно), если ещё нет аккаунта.
2. Создай новый репозиторий, отметь его как **Public**
   (для публичных репозиториев GitHub Actions ничего не стоит и не расходует лимиты).
3. Загрузи в него все файлы из этой папки, сохранив структуру:
   - `monitor.py`
   - `requirements.txt`
   - `.github/workflows/check.yml`

   Проще всего — через веб-интерфейс GitHub: "Add file" → "Upload files",
   перетащи всю папку целиком (GitHub сам сохранит вложенные пути).

## Шаг 3. Добавить секреты

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**

Добавь два секрета:
- `TELEGRAM_BOT_TOKEN` — токен бота из шага 1
- `TELEGRAM_CHAT_ID` — твой chat_id из шага 1

## Шаг 4. Настроить ссылки на поиск

Открой `monitor.py`, в начале файла отредактируй список `SEARCH_URLS`:

```python
SEARCH_URLS = [
    "https://www.kleinanzeigen.de/s-villeroy-boch/k0",
    "https://www.kleinanzeigen.de/s-geschirr-zu-verschenken/k0",
]
```

Замени на свои ссылки: зайди на kleinanzeigen.de, введи нужные ключевые слова
и фильтры (город, категория), скопируй итоговый URL из адресной строки браузера.
Можно добавить сколько угодно строк — под каждый отдельный запрос.

## Шаг 5. Включить Actions и проверить

1. Перейди во вкладку **Actions** репозитория.
2. GitHub может попросить подтвердить включение Actions для репозитория — нажми "I understand, enable".
3. Открой workflow "Kleinanzeigen Monitor" → **Run workflow** — это запустит первую проверку вручную,
   не дожидаясь расписания.
4. Первый запуск ничего не пришлёт в Telegram — он просто запомнит, какие объявления
   уже есть сейчас (чтобы не было спама старыми объявлениями). Дальше, при каждой
   новой проверке, в Telegram будут приходить только новые объявления.
5. После первого запуска дальше всё работает автоматически каждые 5 минут.

## Важные нюансы

- **5 минут** — это практический минимум для GitHub Actions (расписание `cron`
  не гарантирует запуск ровно вовремя, возможны задержки на пару минут при
  большой нагрузке на серверах GitHub — это нормально).
- Если Kleinanzeigen изменит вёрстку страницы, селекторы в `fetch_listings()`
  (например `li.ad-listitem[data-adid]`) может понадобиться обновить — сайт
  время от времени меняет разметку.
- Скрипт не логинится на сайт и не выполняет никаких действий, кроме чтения
  публичных результатов поиска — это обычный просмотр страницы, как в браузере.
- Файл `seen_ads.json` создаётся автоматически в репозитории и постоянно
  обновляется — не удаляй его, иначе получишь повторные уведомления по старым
  объявлениям.
